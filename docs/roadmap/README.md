# Roadmap 维护规范

`docs/ROADMAP.md` 是唯一的长期路线图来源。本目录保存执行规范与模板，不另建重复路线图。

## 更新周期

每周至少更新一次：

1. 当前阶段与完成比例；
2. 本周完成项；
3. 下一周计划；
4. 阻塞与风险；
5. 指标变化和架构决策；
6. 需要团队确认的问题。

## 状态定义

- `Backlog`：尚未排期；
- `Ready`：依赖已满足，可开始；
- `In Progress`：正在实施；
- `Review`：等待代码或方案评审；
- `Blocked`：存在明确阻塞；
- `Done`：满足 Definition of Done。

## 变更规则

涉及架构边界、通信协议、调度策略或关键技术栈的变化，必须新增 ADR，不能只修改 Roadmap。
