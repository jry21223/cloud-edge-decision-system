# 项目背景与问题简述

## 背景

传统纯云端 AI 系统需要上传全部感知数据，容易受到网络延迟、带宽、云端负载和通信中断影响。云边协同通过在靠近数据源的边缘节点部署轻量推理能力，让简单任务快速本地处理，将复杂或不确定任务交给云端，从而平衡时延、准确率和资源消耗。

## 项目目标

构建一个可运行、可演示、可量化的云边协同决策 Demo，能够解释：

1. 为什么某个任务由边缘处理；
2. 为什么某个任务需要上传云端；
3. 云端故障时为什么进入本地降级；
4. 高风险任务为什么必须边缘立即执行安全动作。

## 核心假设

- 边缘模型速度快、资源占用低，但对复杂或边界样本准确率较低；
- 云端模型能力更强，但具有网络和排队成本；
- 通过合理的协同调度，可以在准确率下降有限的条件下降低平均时延、云端调用量和上传数据量；
- 在弱网或断网期间，边缘自治与保守规则能够提高业务完成率。

## MVP 研究问题

第一阶段只验证：

```text
confidence 高 → EDGE
confidence 低 + 云端可用 → CLOUD
confidence 低 + 云端不可用 → EDGE_FALLBACK
高风险任务 → EDGE_SAFETY
```

后续再加入网络状态、节点负载、任务 deadline、多边缘节点和冲突仲裁。
